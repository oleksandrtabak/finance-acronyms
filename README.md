# Абревіатури та основні терміни у корпоративних фінансах 
    
     
     
|         |                                              | **💼 Напрями у фінансах**                          |
| ------- | -------------------------------------------- | -------------------------------------------------- |
| CF      | **C**orporate **F**inance | Управління фінансами компанії |
| IB      | **I**nvestment **B**anking                   | Супровід IPO, M&A-угод, оцінка компаній |
| HF      | **H**edge **F**und                           |  Інвестфонди з гнучкою ризикованою стратегією |
| AM      | **A**sset **M**anagement                     | Управління інвестиційними портфелями клієнтів      |
| WM      | **W**ealth **M**anagement                    | Управління капіталом заможних клієнтів             |
| PWM     | **P**rivate **W**ealth **M**anagement        | Індивідуальні фінансові рішення для HNW-клієнтів   |
| PE      | **P**rivate **E**quity                       | Інвестиції у приватні компанії з ціллю зростання   |
| VC      | **V**enture **C**apital                      | Інвестиції в стартапи на ранніх стадіях            |
| ER      | **E**quity **R**esearch                      | Аналіз публічних компаній і рекомендації по акціях |
| S&T     | **S**ales & **T**rading                      | Продаж та торгівля фінансовими інструментами       |
| PM      | **P**ortfolio **M**anagement                 | Формування та управління інвестпортфелем           |
| RM      | **R**isk **M**anagement                      | Виявлення та контроль фінансових ризиків           |
| FP&A    | **F**inancial **P**lanning & **A**nalysis    | Бюджетування, прогнозування та фінаналіз           |
| FI      | **F**ixed **I**ncome                         | Інструменти з фіксованим доходом (облігації)       |
| RE      | **R**eal **E**state                          | Інвестиції та управління нерухомістю               |
| REIT    | **R**eal **E**state **I**nvestment **T**rust | Фонд, що інвестує в нерухомість                    |
| FinTech | **Fin**ancial **Tech**nology                 | Технологічні рішення у фінансах                    |
| FO      | **F**ront **O**ffice                         | Робота з клієнтами та угодами                      |
| MO      | **M**iddle **O**ffice                        | Ризик-контроль та аналітика                        |
| BO      | **B**ack **O**ffice                          | Облік, кліринг і адміністрування угод              |
      
|          |                                              | **📑 Фінансова звітність**                      |
| -------- | -------------------------------------------- | -------------------------------------------------- |
| BS       | **B**alance **S**heet                        | Показує активи, зобов’язання та капітал компанії   |
| PnL      | **P**rofit & **L**oss                        | Відображає доходи, витрати і чистий прибуток       |
| IS       | **I**ncome **S**tatement                     | Те саме, що PnL, просто більш вживаний термін у США|
| CF       | **C**ash **F**low **S**tatement              | Показує рух грошових коштів компанії               |
| TB       | **T**rial **B**alance                        | Перелік всіх рахунків із залишками                 |
| GL       | **G**eneral **L**edger                       | Головна бухгалтерська книга всіх операцій          |
| MA       | **M**anagerial **A**ccounts                  | Внутрішня управлінська звітність                   |
| QoE      | **Q**uality **o**f **E**arnings              | Аналіз прибутку компанії                           |
| NWC      | **N**et **W**orking **C**apital              | Чистий оборотний капітал (для аналізу ліквідності) |
| GuV      | **G**ewinn und **V**erlust                   | Німецький аналог PnL                               |
| KFR      | **K**apital**f**luss**r**echnung             | Німецький аналог CF                                |
| MD&A     | **M**anagement **D**iscussion & **A**nalysis | Коментар керівництва до фінзвітності               |
| 10-K     | **10**-**K** Report                          | Річний звіт публічної компанії у США               |
| 10-Q     | **10**-**Q** Report                          | Квартальний звіт публічної компанії у США          |
     
|                  |                                                              | **🧩 Елементи PnL **                                |
| ---------------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| COGS             | **C**ost **o**f **G**oods **S**old                           | Собівартість проданих товарів/послуг                 |
| SG&A             | **S**elling, **G**eneral & **A**dministrative                | Операційні витрати на збут і управління              |
| R&D              | **R**esearch & **D**evelopment                               | Витрати на дослідження і розробку                    |
| D&A              | **D**epreciation & **A**mortization                          | Амортизація матеріальних і нематеріальних активів    |
| EBITDA           | **E**arnings **B**efore **I**nterest, **T**axes, **D**&**A** | Операційна прибутковість без впливу боргу і податків |
| EBIT             | **E**arnings **B**efore **I**nterest & **T**axes             | Операційний прибуток до % і податків                 |
| NOPAT            | **N**et **O**perating **P**rofit **A**fter **T**ax           | NOPAT = EBIT × (1 - Tax Rate)                        |
| EBT              | **E**arnings **B**efore **T**axes                            | Прибуток до оподаткування                            |
| OPEX             | **O**perating **Ex**penses                                   | Сукупні операційні витрати                           |
| CAPEX            | **C**apital **Ex**penditure                                  | Інвестиції у довгострокові активи                    |

|           |                                                                                     | **🧩 Елементи балансу **                   |
| --------- | ----------------------------------------------------------------------------------- | ------------------------------------------- |
| A = E + L | **A**ssets = **E**quity + **L**iabilities                                           | Базове рівняння балансу                     |
| DEA LER   | **D**ividends, **E**xpenses, **A**ssets = **L**iabilities, **E**quity, **R**evenue  | DEA збільшується по дебету і зменшується по кредиту; LER — навпаки  |
| CСE       | **C**ash and **C**ash **E**quivalents                                               | Гроші та їх еквіваленти                     |
| AR        | **A**ccounts **R**eceivable                                                         | Дебіторська заборгованість                  |
| AP        | **A**ccounts **P**ayable                                                            | Кредиторська заборгованість                 |
| PP&E      | **P**roperty, **P**lant & **E**quipment                                             | Основні засоби                              |
| STL       | **S**hort-**T**erm **L**iabilities                                                  | Поточні зобов’язання                        |
| LTL       | **L**ong-**T**erm **L**iabilities                                                   | Довгострокові зобов’язання                  |
| RE        | **R**etained **E**arnings                                                           | Нерозподілений прибуток                     |
| TA        | **T**otal **A**ssets                                                                | Загальна сума активів                       |

|           |                                                  | **🏢 Оцінка **                                  |
| --------- | ------------------------------------------------ | :----------------------------------------------- |
| WACC      | **W**eighted **A**verage **C**ost of **C**apital | Середньозважена вартість капіталу, як фактор дисконтування  |
| DCF       | **D**iscounted **C**ash **F**low                 | Оцінка бізнесу через дисконтовані грошові потоки |
| DDM       | **D**ividend **D**iscount **M**odel              | Оцінка компанії через дисконтовані дивіденди     |
| CCA       | **C**omparable **C**ompanies **A**nalysis        | Порівняльний аналіз схожих компаній              |
| CTA       | **C**omparable **T**ransactions **A**nalysis     | Порівняльний аналіз подібних M&A-угод            |
| M&A       | **M**ergers & **A**cquisitions                   | Угоди злиття і поглинання                        |
| FDD       | **F**inancial **D**ue **D**iligence              | Фінансова перевірка перед угодою                 |
| EV        | **E**nterprise **V**alue                         | Загальна вартість бізнесу (борг + капітал)       |
| EqV       | **E**quity **V**alue                             | Вартість власного капіталу (в публічних компанія - це те саме, що й Market Cap) |


|           |                                          | **📈 Фінансові метрики**             |
| --------- | ---------------------------------------- | :----------------------------------- |
| D/E       | **D**ebt / **E**quity                    | Левередж (борг до капіталу)          |
| P/E       | **P**rice / **E**arnings                 | Ціна до прибутку                     |
| P/B       | **P**rice / **B**ook                     | Ціна до балансової вартості          |
| EV/EBITDA | **E**V / **E**BITDA                      | Вартість бізнесу до операц. прибутку |
| DSO       | **D**ays **S**ales **O**utstanding       | Дні очікування оплати від клієнтів   |
| DPO       | **D**ays **P**ayable **O**utstanding     | Дні оплати постачальникам            |
| DIO       | **D**ays **I**nventory **O**utstanding   | Дні зберігання запасів               |
| CCC       | **C**ash **C**onversion **C**ycle        | Грошовий операційний цикл            |
| FCFF      | **F**ree **C**ash **F**low to **F**irm   | Потік для всіх інвесторів            |
| FCFE      | **F**ree **C**ash **F**low to **E**quity | Потік для власників капіталу         |


|         |                                                                                | **🔄 Переоцінка **                    |
| ------- | ------------------------------------------------------------------------------ | :------------------------------------- |
| FV      | **F**air **V**alue                                                             | Справедлива ринкова вартість           |
| FVOCI   | **F**air **V**alue through **O**ther **C**omprehensive **I**ncome              | Переоцінка через інший сукупний дохід  |
| FVTPL   | **F**air **V**alue through **P**rofit or **L**oss                              | Переоцінка через P&L                   |
| AC      | **A**mortized **C**ost                                                         | Амортизована вартість                  |
| OCI     | **O**ther **C**omprehensive **I**ncome                                         | Інший сукупний дохід                   |
| ECL     | **E**xpected **C**redit **L**oss                                               | Очікувані кредитні збитки              |
| EAR     | **E**ffective **A**nnual **R**ate                                              | Ефективна річна ставка                 |
| SPPI    | **S**olely **P**ayments of **P**rincipal and **I**nterest                      | Критерій для класифікації фін. активів |
| IFRS    | **I**nternational **F**inancial **R**eporting **S**tandards                    | Міжнародні стандарти обліку (на основі принципів)       |
| GAAP    | **G**enerally **A**ccepted **A**ccounting **P**rinciples                       | Національні стандарти обліку  (на основі правил)        |

Цей репо створено як невеличкий словник-шпаргалку на основі моєї роботи на посаді фінансового аналітика в PwC.
